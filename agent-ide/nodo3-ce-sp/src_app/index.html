📐 Le Formule Matematiche del Bilancio (Zero Probabilità AI)

Tutti i conti dell'applicazione vengono calcolati tramite formule matematiche fisse e trasparenti, senza affidarsi ai calcoli probabilistici dell'Intelligenza Artificiale:

• EBITDA = Valore Produzione - (OpEx + Personale + TFR)
• EBIT = EBITDA - Ammortamenti (Software + Server HW)
• EBT = EBIT + Proventi Finanziari - Oneri Finanziari
• Utile Netto = EBT - Imposte (IRES 24% + IRAP 3.9%)
• Cassa Netta = Cassa_Precedente + Utile + Ammortamenti - CapEx
• Quadratura SP: Totale Attivo === Totale Passivo (Verificato in <1ms)

📐 Formulario Matematico Deterministico (Zero LLM)

Tutti i totali e i margini del bilancio sono calcolati tramite le seguenti equazioni matematiche fisse nel codice JavaScript/Python:

1. Conto Economico (Art. 2425 C.C.)

ValoreProduzione (A) = RicaviVendite + AltriRicavi
OpexTotale (B.6..B.14) = MaterieHosting + ServiziMarketing + GodimentoBeni + OneriDiversi
PersonaleTotale (B.9) = SalariStipendi + OneriSociali + QuotaTFR

EBITDA = ValoreProduzione - (OpexTotale + PersonaleTotale)
AmmortamentiTot = AmmImmateriali + AmmMateriali + SvalutazioneCrediti
EBIT = EBITDA - AmmortamentiTot
EBT = EBIT + ProventiFinanziari - OneriFinanziari

IRES = max(0, EBT) * 0.24
IRAP = max(0, EBITDA) * 0.039
UTILE_NETTO = EBT - (IRES + IRAP)

2. Stato Patrimoniale & Cassa (Art. 2424 C.C.)

ImmobilizzazioniNette = (ImmaterialiLorde - FondoAmmImm) + (MaterialiLorde - FondoAmmMat) + Finanziarie
AttivoCircolante = Cassa + CreditiClienti + CreditiTributari
TOTALE_ATTIVO = ImmobilizzazioniNette + AttivoCircolante

PatrimonioNetto = CapitaleSociale + RiservaLegale + RiserveUtili + UtileNetto
TotaleDebiti = DebitiBanche + DebitiFornitori + DebitiTributari + DebitiINPS
TOTALE_PASSIVO = PatrimonioNetto + FondiRischi + FondoTFR + TotaleDebiti

QUADRATURA: TOTALE_ATTIVO === TOTALE_PASSIVO (Verificato <1ms)
